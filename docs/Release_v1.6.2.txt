Arculus v1.6.2 - Release Notes
==============================

Release date: 2026-06-17

Release summary
---------------

Arculus_Recovery.html v1.6.2 adds live, case-insensitive partial filtering of
derived table rows by address, private key, or other displayed row data. The
filter remains available in the expanded output view and reports matching and
total row counts.

The Python package, CLI version, packaged Python GUI WebView asset, and Tauri
wrappers are promoted to v1.6.2. ARC V2 backup formats and derivation behavior
are unchanged from v1.6.1.

Release boundary
----------------

The archived standalone browser builds are stored at:

  lts/Arculus_Recovery_v1.6.0_LTS.html
  lts/Arculus Recovery_v1.5.0_LTS.html

Arculus_Beta.html is the tracked development candidate for a future v1.6.3.
Its unreleased security, settings, and lifecycle changes are not part of the
v1.6.2 release artifacts or byte-level compatibility target.

  releases/tauri/macos/Arculus Recovery x64.app
  releases/tauri/macos/Arculus Recovery.app
  releases/tauri/macos/Arculus Recovery Universal.app

The recorded macOS build environment was:

  macOS: 15.7.7
  host architecture: arm64
  rustc: 1.96.0 (ac68faa20 2026-05-25)
  cargo: 1.96.0 (30a34c682 2026-05-25)
  tauri-cli: 2.11.2

The build commands were:

  python scripts/prepare_tauri_assets.py
  CARGO_TARGET_DIR=/tmp/arculus-tauri-target cargo tauri build --target x86_64-apple-darwin --bundles app,dmg
  CARGO_TARGET_DIR=/tmp/arculus-tauri-target cargo tauri build --target aarch64-apple-darwin --bundles app,dmg
  CARGO_TARGET_DIR=/tmp/arculus-tauri-target cargo tauri build --target universal-apple-darwin --bundles app,dmg

The repository was on an exFAT volume during the macOS builds, so
CARGO_TARGET_DIR was moved to /tmp to avoid macOS AppleDouble files named ._*
inside Cargo and Tauri generated directories. The .app bundles were ad-hoc
signed with codesign -s -. The DMGs were rebuilt from the signed app bundles
and verified with hdiutil verify. They are not Apple-notarized.

Verification confirmed:

  Arculus Recovery x64.app: x86_64
  Arculus Recovery.app: arm64
  Arculus Recovery Universal.app: x86_64 and arm64
  CFBundleShortVersionString: 1.6.2
  CFBundleVersion: 1.6.2
  CFBundleIdentifier: com.arculus.recovery
