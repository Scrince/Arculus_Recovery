YellowSphere v1.6.6 - Release Notes
==============================

Release date: 2026-06-26

YellowSphere.html reports APP_VERSION 1.6.6 and displays "YellowSphere v1.6.6".
The previous production standalone HTML build is archived as:

  lts/YellowSphere_v1.6.4_LTS.html

The beta standalone HTML filename has been retired for this promotion. The
canonical browser application is again:

  YellowSphere.html

Highlights
----------

- Promoted the reviewed beta browser build to the production filename.
- Kept keyfile drag-and-drop support limited to keyfile import rows.
- Made keyfile drop targets easier to recognize with a persistent dashed
  outline, drop icon, helper text, and stronger drag-over highlight.
- Added Playwright coverage for keyfile picker import, keyfile drag-and-drop
  import, encrypted keyfile import, wrong-password handling, and CSP hash
  enforcement.
- Deferred browser object URL revocation after downloads to improve browser
  download reliability.
- Consolidated global Escape-key handling for QR modal and expanded output
  panel behavior.
- Cleaned idle-warning state when sensitive fields are cleared.

The Windows artifacts are unsigned. Python, Windows, macOS, and Linux release
artifacts for v1.6.6 are checked in under `releases/` and hashed in
`docs/SHA256SUMS`. Existing older artifacts and hashes remain historical
records.

PGP release signatures
----------------------

Detached ASCII-armored PGP signatures are included next to YellowSphere.html
and the rebuilt Python and Windows artifacts as `.asc` files. The
release-signing public key is:

  docs/YellowSphere_Release_Signing_2026_pubkey.asc

Release signing key:

  YellowSphere Release Signing (2026) <release@yellowsphere.local>
  Fingerprint: 6A88 D329 DCF6 1A44 EF69 101B 019E C328 3B45 1469

Verify the public key fingerprint before trusting signatures:

  gpg --show-keys docs/YellowSphere_Release_Signing_2026_pubkey.asc

Verify the checksum manifest:

  gpg --verify docs/SHA256SUMS.asc docs/SHA256SUMS

Verify a signed artifact:

  gpg --import docs/YellowSphere_Release_Signing_2026_pubkey.asc
  gpg --verify YellowSphere.html.asc YellowSphere.html
  gpg --verify releases/tauri/windows/YellowSphere_1.6.6_x64-setup.exe.asc releases/tauri/windows/YellowSphere_1.6.6_x64-setup.exe

These PGP signatures provide release-integrity verification. They do not replace
Windows Authenticode signing, so Windows may still report the installers as
having no trusted publisher.
